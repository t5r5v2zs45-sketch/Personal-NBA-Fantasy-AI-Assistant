My NBA Fantasy AI Assistant

A personal, non-commercial analytics project for a private Yahoo Fantasy Basketball league. The assistant is designed to support informed roster decisions in a 14-team Head-to-Head, nine-category league.

Planned features

  • Analyze league settings, team rosters and weekly matchups.
  • Compare available free agents with rostered players across nine fantasy categories.
  • Evaluate potential trades and add/drop decisions.
  • Identify category strengths, weaknesses and possible punt strategies.

Data access and security

The planned integration will request authorization through Yahoo OAuth 2.0 and use read-only Fantasy Sports API access. Users will not enter their Yahoo passwords into this website. Any authorized access tokens will be handled by a separate secure backend, not stored in this static page.

Privacy and data use

This website does not provide account login, collect personal information, use analytics trackers or set cookies. If the planned integration is approved and implemented, league data will be accessed solely to generate personal fantasy basketball recommendations. Data will not be sold or made available to other users. Authorized access can be revoked through Yahoo account settings.

Project status

This project is currently under development. The Yahoo Fantasy Sports API integration is subject to Yahoo approval. No Yahoo affiliation, endorsement or official partnership is claimed.
